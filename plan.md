# Ricursive — HackMD Trial Success Plan

> **Trial Period:** 4 weeks  
> **Environment:** Prime Team on HackMD production (hackmd.io) 
> **Starting Group:** Felix Wong, Jerry Cheng, Jiwoo Pak + 1~2 interested teammates

---

## Goal

Ricursive regularly stores markdown into a GitHub repo, but the repo has no collaborative layer before a doc is considered final:
- Highlighting
- Commenting and suggest editing
- Real-time co-editing 
 
Goal is to enable the team to collaborate (in HackMD), then store a finished version (in GitHub) once everyone agrees. 

---

## 4-Week Plan

| Week | Goal | Milestone |
|---|---|---|
| Week 1: Kickoff | Onboard the initial 3-5 users; first doc co-edited and pushed to GitHub | 1 doc live in HackMD, 1 manual push to GitHub |
| Week 2: Real Work | HackMD replaces ad hoc review (Slack threads, Google Docs) for one real doc | ≥1 recurring workflow running in HackMD |
| Week 3: Expand | Widen to 5-10 users team if Week 1–2 landed well | Comments/highlights actively used by the group |
| Week 4: Decision | 30-min review call; Felix + Jerry recommend (or not) purchasing the company-wide Enterprise plan | Go/no-go decision made |

---

## Success Metrics

| Metric | Target |
|---|---|
| Participation | ≥5 of the team actively editing weekly |
| Real workflow | ≥5 recurring doc/workflow run through HackMD|
| Collaboration usage | Comments, Suggest Edit, and highlights actively used, not just plain editing |
| Data comfort | No blocking concern raised about content living in the shared production trial workspace |
| Decision readiness | Felix + Jerry have a clear recommendation by end of Week 4 |

---

## Commitments

**HackMD:** 
- Guided onboarding for the starting group
- Weekly 30-min check-in
- Maintain Data Security SLA of HackMD Production service

**Ricursive:** 
- Jerry or Jiwoo as the trial point of contact
- At least one real recurring workflow run through HackMD (beyond kicking tires) 
- ==No highly sensitive codebase/algorithm content in the trial workspace== until a self-hosted or dedicated-instance decision is made

---

## Path Forward

A successful trial means Felix, Jerry, and Jiwoo can bring a clear recommendation back internally; the next conversation is which hosting model the company-wide Enterprise plan runs on.

This trial only tests whether the collaboration workflow itself is worth adopting. It doesn't resolve on-premise vs. cloud — Ricursive said that decision waits on their security review, which the signed NDA and shared SOC 2 / pentest reports were meant to unblock.
